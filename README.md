# Lumber Empire

Mobile-first lumber tycoon prototype.

## Prototype 0.1
- Touch joystick movement
- Chop trees
- Carry logs
- Process logs in the sawmill
- Carry planks
- Sell planks for cash
- Trees respawn so the loop is endless

The prototype is intentionally dependency-free: HTML5 Canvas + JavaScript. This lets us test the core gameplay on a phone before moving to a full 3D production engine.

## Controls
- Mobile: drag the joystick at bottom-left. Walk near a tree to chop automatically. Walk to the sawmill to process carried logs, then to the sell zone with planks.
- Desktop: WASD / arrow keys.
